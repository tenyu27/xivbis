# Job icons

Downloaded on 2026-09-17. All images are hosted locally and preserved without modification.

The 23 job icons come from the navigation links on the official [FINAL FANTASY XIV Job Guide](https://na.finalfantasyxiv.com/jobguide/battle/). The generic empty fallback comes from the XIVAPI Companion icon collection at the pinned commit linked below.

Artwork © SQUARE ENIX. Use is subject to Square Enix's [Materials Usage Policy](https://support.na.square-enix.com/rule.php?id=5382&tag=authc).

## Updating

Find each job's image URL in the Job Guide's navigation, download it under its existing filename, and update the source link and download date here. For a new job, add its abbreviation and filename to `src/constants.ts`. Keep `none.png` available for unknown jobs and failed image loads. Commit the PNG files with the mapping changes; no download is required at build time or runtime.
